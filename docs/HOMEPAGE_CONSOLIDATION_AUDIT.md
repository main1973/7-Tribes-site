# Homepage Consolidation Audit

## Purpose

This audit applies the approved homepage journey without changing the established black-and-gold visual system, 7TRB symbol, typography, cards, gradients, mobile header, public Academy challenge, or active ecosystem destinations.

> **Approved visitor journey:** What it is → how it works → where I fit → what I can learn → why it matters → what organized participation could do → where it starts → how I join.

## Consolidation rules

The consolidated homepage will retain every working external destination and interactive tool. The only removed material is repeated conceptual explanation or a repeated CTA where the same destination remains available through the primary ecosystem map, final CTA, or footer.

The Community Scenario Lab will retain this visible disclaimer:

> This scenario tool is educational and does not represent live 7Tribes ecosystem metrics.

All generated scenario values will remain labeled **Illustrative**. No membership counts, merchant counts, transactions, projects, participation rates, testimonials, or growth claims will be invented or presented as live platform statistics.
